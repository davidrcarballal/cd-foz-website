# cd-foz-website

Website for CD Foz - Web Development Assignment 2

## Description

This project is a responsive static website dedicated to Club Deportivo Foz,
a football club from Foz, Lugo, Galicia.
The purpose of this website is to promote the club, its identity and its football matches,
while providing a simple and interactive user experience.

## Data Processing

Match information is stored in a JSON file.
JavaScript processes the dates, scores and team shield
identifiers before dynamically displaying the match cards.This website is an unofficial academic project.
Match results are fictional and are used for demonstration purposes only.
